## 이미지와 상대 링크

문서 옆에 둔 이미지는 상대 경로로, 다른 노트는 `.md` 경로로 links합니다. 미리보기에서는
열어 둔 문서의 폴더를 기준으로 찾습니다.

```markdown
![사진](photo.png)
[다른 노트](other.md)
```

## 이 노트에서 동작하지 않는 것

글이 사라지지 않습니다.
